# 数据集

| 文件              | 编码  | 用途           |
|-------------------|-------|----------------|
| `customers.csv`   | UTF-8 | 客户聚类       |
| `orders.csv`      | GBK   | 购物篮订单     |
| `items.csv`       | GBK   | 商品与类别映射 |
| `temperature.csv` | UTF-8 | 日温度预测     |
| `scores.csv`      | UTF-8 | 成绩统计       |
| `turnover.csv`    | UTF-8 | 销售相关性     |

读取 GBK 文件时显式传入 `encoding="gbk"`。
